## Requirement lifecycle

- `planned`: part of the target contract but not implemented.
- `in_progress`: implementation exists but acceptance evidence is incomplete.
- `verified`: the exact acceptance evidence has passed and is linked from `IMPLEMENTATION_STATUS.md`.

All rows begin as **planned**. Update lifecycle and evidence only when a phase's exit criteria have actually passed.
